# 로그인 모듈 사용법 (geometrybook.storage 패키지)

ERD v2의 `student` → `data/students.csv`를 읽고 쓰는 모듈입니다. 화면 코드는 **`AuthService`만** 쓰면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `AuthService` | 화면이 부르는 창구: 회원가입, 로그인, 로그아웃, 현재 학생, 비밀번호 변경 |
| `Student` | 학생 계정 데이터 클래스 (CSV 한 행 ↔ 객체) |
| `StudentRepository` | students.csv 읽기·쓰기, id·loginId 중복 검사 |
| `CsvCodec` | CSV 공통 파서 (쉼표·따옴표·줄바꿈 인용 규칙, 임시 파일 → 교체 저장). 다른 CSV에도 재사용 |
| `PasswordHasher` | 비밀번호 PBKDF2 해시 (평문 저장 안 함) |
| `DataFileException` | 파일이 깨졌거나 규칙 위반일 때 |
| `src/test/java/.../AuthServiceTest` | main으로 돌리는 테스트 20개 (앱 실행에는 필요 없음) |

## 화면에서 쓰는 법

```java
import geometrybook.storage.AuthService;
import geometrybook.storage.Student;
import java.nio.file.Path;
import java.util.Optional;

AuthService auth = new AuthService(Path.of("data"));   // 앱 시작 시 한 번 만들어 공유

// 로그인 버튼
Optional<Student> me = auth.login(idField.getText(), new String(pwField.getPassword()));
if (me.isPresent()) {
    // 메인 화면으로. 다른 화면에서는 auth.getCurrentStudent().getId() 로 학생 id 사용
} else {
    JOptionPane.showMessageDialog(frame, "아이디 또는 비밀번호가 틀렸어요.");
}

// 회원가입 버튼 (학년 미입력이면 null)
try {
    auth.register(id, pw, nickname, grade);
} catch (IllegalArgumentException e) {
    JOptionPane.showMessageDialog(frame, e.getMessage());   // 한국어 안내 문구가 들어 있음
}

// 아이디 중복 확인 버튼
boolean ok = auth.isLoginIdAvailable(id);

// 로그아웃
auth.logout();
```

## 규칙 (팀에서 정하면 AuthService 상단 상수만 바꾸면 됨)

- 아이디: 영문·숫자·_ 4~20자, 중복 불가
- 비밀번호: 4~30자 (ERD 7장 미정 사항)
- 닉네임: 1~12자, 중복 허용
- 학년: 1~6 또는 미입력
