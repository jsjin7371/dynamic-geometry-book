# 도형탐험대 기능명세서

## 1. 목적·구조·적용 기준

초등 3~4학년이 Java Swing 데스크톱 앱에서 도형을 순서대로 배우고, 퀴즈와 오답노트로 복습한다. 파스텔 색상과 도형 캐릭터를 사용한다.

**한 PC에서 UI·학습 처리·파일 입출력이 함께 실행된다. 모든 영구 데이터는 해당 PC의 TXT/CSV 파일로 관리한다.** 여러 학생이 각자의 로컬 계정으로 로그인하며 계정 없이는 학습할 수 없다. DB 제품이나 서버 구축은 필요하지 않다.

최신 인터뷰가 과거 결정에 우선한다. 서버 계정, 여러 PC 자동 공유, 게스트 학습, 계정 연결·병합, 재연결 동기화 요구는 폐기한다. 인터넷 연결 여부와 관계없이 동일한 기능을 제공한다.

이 문서는 개발 명세다. 기존 Swing 로그인 코드는 입력 검증 등을 제공하는 데모이며 실제 파일 인증·학습 기능 구현 완료를 의미하지 않는다. 기존 [Figma UI](https://www.figma.com/design/NBHcvfXRioQPk9GvUz35eA)의 예시 수치와 이전 안내보다 본 문서가 우선한다.

‘확정’은 사용자 답변, ‘설계안’은 구현을 위한 제안, ‘미정’은 추후 결정 사항이다. 아래 예외·저장 세부 방식은 별도 확정 표시가 없으면 설계안이다. **A안**은 이번에 구현할 범위이고, **B안**은 시간이 나면 추가할 범위다.

## 2. 확정 정책

용어: **세부페이지**는 도형 설명과 애니메이션 화면, **퀴즈패널**은 세부페이지 학습 후 바로 보이는 퀴즈(`LessonPanel.showQuizPanel()`), **퀴즈페이지**는 퀴즈만 풀 수 있는 별도 메뉴(`QuizPage`)다. **레벨**은 도형 하나의 학습 단위(7개)로, 코드에서는 `Level` enum, CSV에서는 `levelId`다. **레슨**은 레벨 하나를 학습하는 화면(`LessonPanel`)이다.

### A안 (이번 구현 범위)

| 항목 | 결정 |
|---|---|
| 사용자 | 한 PC에 여러 학생 계정, 아이디·비밀번호 로그인 유지 |
| 비로그인 | 로그인만 이용 가능. 학습 시작 불가 |
| 학습 과정 | 초기 7레벨, 향후 추가 가능 |
| 순차 진행 | 선행 레벨 완료 후 다음 레벨 열림 |
| 학습 흐름 | 세부페이지에서 ‘설명 학습 완료’를 누른 뒤 퀴즈패널로 이동 |
| 퀴즈패널 문제 | 레벨별 고정 객관식 3문제, 문제마다 정답 1개. 코드(`Level`)에 보관 |
| 퀴즈페이지 문제 | OX 또는 객관식, 문제 수 제한 없음. `questions.csv`·`answer_choices.csv`에 보관 |
| 퀴즈페이지 이용 | 학습 완료 여부와 관계없이 이용 가능 |
| 재도전 | 퀴즈패널은 맞힌 문제를 유지하고 틀린 문제만 다시 풂. 퀴즈페이지는 결과 화면에서 틀린 문제만 다시 풂 |
| 완료 | 퀴즈패널의 3문제를 모두 맞히면 레벨 완료. 퀴즈페이지 결과는 완료에 반영하지 않음 |
| 복습 | 완료한 레벨의 세부페이지와 퀴즈패널을 다시 볼 수 있음. 설명 생략 가능, 3문제를 다시 모두 맞힘 |
| 중간 학습 | 세부페이지를 보던 위치와 풀던 답은 저장하지 않음. 레벨 완료 여부만 저장 |
| 오답 기록 | 퀴즈페이지에서 틀린 순간 파일에 저장 |
| 오답 복습 | 오답노트나 퀴즈페이지 결과 화면에서 틀린 문제를 다시 풀고, 맞히면 파일에서 삭제 |

## 3. 화면별 기능

### A안 (이번 구현 범위)

| ID | 화면·기능 | 입력·처리·결과 |
|---|---|---|
| AUTH-02 | 로그인 | 로컬 계정 파일의 아이디와 비밀번호 검증값을 확인. 성공 시 현재 학생 ID를 메모리에 설정하고 메인 진입. 실패 시 통합 오류 안내 |
| AUTH-06 | 로그아웃 | 진행 중 학습을 종료하고 로그인 화면 이동. 다음 학생에게 이전 학생의 화면·답안 상태가 남지 않음 |

| HOME-02 | 학습 시작 | 다음 진행 가능한 레벨 또는 완료 레벨 복습으로 이동. 저장된 중간 지점 이어하기는 제공하지 않음 |

| LV-03 | 복습 시작 | 완료 레벨의 세부페이지와 퀴즈패널을 다시 볼 수 있음. 설명은 선택, 문제는 새로 시작 |

| QUIZ-04 | 퀴즈패널 중단 처리 | 학습 종료·로그아웃·앱 종료 시 미완료 학습을 버림. 다음 진입은 설명부터(복습은 생략 가능). 진행 중 화면 이탈에는 확인 안내 |

## 4. 과정·상태·계산

### 초기 레벨

| 임시 순서 | 도형 | 담당 |
|---|---|---|
| 1 | 삼각형 | 사공우혁 |
| 2 | 정사각형 | 박지호 |
| 3 | 직사각형 | 김승규 |
| 4 | 마름모 | 사공우혁 |
| 5 | 사다리꼴 | 김승규 |
| 6 | 평행사변형 | 박지호 |
| 7 | 원 | 사공우혁 |

7개 구성은 확정이다. 최종 순서는 세부페이지를 합칠 때 정하며, 표의 순서는 현재 코드가 쓰는 임시 순서다. 이후 레벨을 추가해도 기존 ID를 바꾸지 않는다.

### 학습 상태

- **학습:** 로그인 → 가능한 레벨 선택 → 세부페이지 → 퀴즈패널 → 3문제 모두 정답 → `progress.csv`에 완료 저장 → 완료 결과
- **복습:** 완료한 레벨의 세부페이지와 퀴즈패널을 다시 볼 수 있고, 설명은 건너뛸 수 있다. 완료 여부는 바뀌지 않으며 복습 기록은 따로 저장하지 않는다.
- **퀴즈페이지:** 퀴즈 메뉴 → 단원 선택 → 문제 풀이 → 틀린 순간 `wrong_answers.csv`에 저장 → 결과 → 틀린 문제 다시 풀기. 맞히면 `wrong_answers.csv`에서 삭제한다. 레벨 완료에는 반영하지 않는다.
- **오답노트:** 틀린 문제 목록 → 다시 풀기 → 맞히면 `wrong_answers.csv`에서 삭제
- **중단:** 세부페이지를 보던 위치, 풀던 답, 정답 누적 상태는 메모리에만 두고 중단하면 폐기한다. 이미 저장한 오답은 유지한다.

### 포인트·날짜·랭킹 (B안)

- 같은 레벨 최초 완료는 한 번, 복습은 여러 번 기록할 수 있다.
- 학습일은 완료 시각 기준이다. 설명을 보거나 문제 일부를 맞힌 날은 학습일이 아니다.
- 서로 다른 완료 날짜를 정렬하여 하루씩 이어지는 구간을 계산한다. 3일째 20P, 7일째 50P를 지급한다. 같은 날 반복 완료로 연속일은 늘지 않는다. 10일·14일째 반복 보상은 없다.
- 하루를 빠뜨리면 다음 학습일부터 새 구간이며 새로 3일/7일 보상 가능. 단순 중단으로 이미 받은 포인트를 회수하지 않는다.
- 누적 포인트 = 학생별 지급 기록 금액 합. 랭킹 순위 = 본인보다 포인트가 높은 학생 수 + 1. 동점 행의 표시 순서는 학생 ID로 안정화하는 설계안이며 순위는 같다.
- 현재 연속일은 오늘 기록이 있으면 오늘, 없고 어제 기록이 있으면 어제 기준, 둘 다 없으면 0으로 표시하는 설계안이다.

## 5. 파일 관리와 프로그램 책임

화면(Swing) → 학습·계정 처리 → 파일 저장 모듈 → CSV. 모두 같은 프로그램 내 구성 요소다. 네트워크 API 호출·서버 토큰·DB 접속은 없다.

### A안 파일

| 데이터 | 파일 |
|---|---|
| 학생 계정 | students.csv |
| 레벨 | levels.csv |
| 퀴즈페이지 문제·보기 | questions.csv, answer_choices.csv |
| 레벨 완료 여부 | progress.csv |
| 오답 기록 | wrong_answers.csv |

세부페이지의 설명·애니메이션과 퀴즈패널 문제는 파일로 관리하지 않고 앱 코드에 포함한다.

파일별 열·참조는 [ERD.md](ERD.md)에 정의한다. 단, `progress.lastSceneNo`와 `question.reviewSceneNo`는 A안 정책에서 사용하지 않는다. 기본키·외래키·중복 제한은 Java 코드가 검사한다. 비밀번호는 원문 대신 salt·알고리즘·작업량 정보를 포함한 비밀번호 검증값으로 저장한다. 모든 파일이 로컬이므로 OS에서 파일을 직접 수정하는 사용자까지 앱 로그인만으로 막을 수는 없다.

### 저장 방식

파일을 저장할 때는 임시 파일에 먼저 쓴 뒤 원본과 교체해, 저장이 실패해도 기존 파일을 유지한다. 저장에 실패하면 완료 결과를 성공으로 표시하지 않는다.

긴 파일 입출력은 Swing 화면을 멈추지 않도록 작업 스레드에서 처리하고 화면 갱신은 EDT에서 수행한다. 저장 중 중복 클릭을 차단하고 성공 확인 전 결과 화면을 확정하지 않는다.

| 데이터 | 파일 |
|---|---|
| 난이도별 보상 | difficulties.csv |

| 학습 완료 기록 | completions.csv |
